Trabalho de Rede Hierárquica Colapsada — CST em Redes de Computadores

Estrutura implementada:
- Camada de Núcleo: 1 roteador + 2 switches, com agregação de link de 4Gbps entre os switches centrais; roteador conectado com duas interfaces FastEthernet, uma em cada switch de núcleo.
- Camada de Distribuição: Conexões com os switches de núcleo feitas por fibra óptica, com agregação de link de 2Gbps para cada par de conexão.
- Camada de Borda: 4 switches de acesso, sem ligação direta entre si, conectados apenas aos switches de distribuição.
- Dispositivos Finais: 4 computadores desktop, 4 notebooks e 1 servidor, todos conectados por cabo de par trançado.
